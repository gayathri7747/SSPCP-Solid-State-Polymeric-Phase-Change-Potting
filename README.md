# SSPCP – Solid-State Polymeric Phase-Change Potting System

**SENSE. ANALYSE. ACT. VERIFY.**

> SIH 2026 prototype | Problem ID: SIH26049 | Enhancing Electronic Reliability & Efficiency in Extreme High-Altitude Environments (Ladakh) | Team: NOVAZYN (ID 164141)

## About
An intelligent environmental protection system for electronics at high altitude. An ESP32 monitors temperature, pressure, humidity, voltage and current, controls a heater when it gets too cold, and shows real-time status and alerts on an OLED display. The electronics are protected by polymeric potting combined with phase-change material (PCM).
